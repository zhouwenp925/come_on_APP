# Android 真机设置与验收

适用于 Android 10 及以上。请记录实际测试设备、系统版本和测试结果，厂商后台策略需要分别验收。

## 首次设置

1. 安装正式 APK，打开「收心 → 今天 → 开启使用情况访问」，在系统列表选择收心并允许。此权限用于读取前台事件，不读取屏幕内容或聊天消息。
2. 点击「允许鼓励通知」。到「我的 → 设置通知声音和渠道」确认“鼓励提醒”“专注计时结束”允许显示；默认无声音。是否悬浮或锁屏展示由系统通知设置决定。
3. 选择一个实际娱乐 APP，主动开启 1 小时守护，确认通知栏有“收心守护已开启”和停止按钮。
4. 如果 OriginOS 会提前关闭守护或迟迟不给提醒，在系统设置搜索“后台耗电管理”或“后台高耗电”，为收心允许后台运行；必要时再查“自启动”。自启动权限仅帮助定时计划恢复，重启后收心不会自动开启实时守护。
5. 定时鸡汤进入「规则 → 设置定时鸡汤 / 设置间隔鸡汤」。Android 12+ 点「允许准时提醒」，允许系统「闹钟与提醒」并返回。定时鸡汤不要求使用访问或守护；规则开关、静默、冷却和上限仍需核对。

vivo 官方客服资料列出了“设置 → 电池 → 后台耗电管理/后台高耗电”和“设置 → 应用与权限 → 权限管理 → 自启动”的参考路径。资料较早，本机菜单可能不同，建议以设置搜索结果为准，不把这些路径视为该软件版本已验证的界面。[vivo 客服说明](https://kefu.vivo.com.cn/robot/imgmsgData/2616a9cd7cd64a5083a264d16e5767da/index_1.html)

守护运行时可能增加耗电，按需要开启。勿扰、省电模式、强行停止 APP 仍可能影响提醒；允许后台权限不构成准时送达保证。

## 验收清单

| 操作 | 预期 | 实测结果 |
|---|---|---|
| 未给使用访问，打开今天 | 显示尚无有效数据和授权入口，不展示伪造的零时长 | 待测 |
| 给权限，打开/退出娱乐 APP，回到收心刷新 | 今天的估算时长与排名增加，标明估算和刷新时间 | 待测 |
| 规则中发一条预览 | 通知可见，不消耗每日鼓励额度 | 待测 |
| 连续阈值临时设为 1 分钟，开守护持续使用娱乐 APP | 达阈值后有效评估提交一条；同一连续会话不重复刷屏 | 待测 |
| 娱乐组内两个 APP 切换 | 连续会话接续；组外短切换不算娱乐时长 | 待测 |
| 锁屏/离开组超过 60 秒，再回到目标 APP | 开启新的连续会话 | 待测 |
| 系统通知点击稍后；再连点 | 仅排一个 10 分钟后提醒，仍需当时满足触发条件，最多两次 | 待测 |
| 安静时段和今天暂停 | 不提交普通鼓励；今天暂停在次日解除 | 待测 |
| 设置未来几分钟的固定提醒 | 正常允许后台时提交，记录实际延迟；迟到超过 5 分钟不补发 | 待测 |
| 未允许 / 允许「闹钟与提醒」后返回 APP | 未允许可保存普通计划；允许后重新安排精确定时；界面状态更新 | 待测 |
| 定时与间隔选择「励志金句」，不启用守护 | 收到励志短句；文案库可核对来源、收藏及屏蔽 | 待测 |
| 开始 5 分钟专注，锁屏再返回 | 计时按单调时钟恢复，不因界面退出重新计时 | 待测 |
| 重启手机 | 守护关闭，运行中专注记为中断，定时计划恢复 | 待测 |
| 撤销使用访问 / 通知权限 | 采集/发送停止或不可用；原记录保留，其他页面能使用 | 待测 |
| 停止守护 / 到时自动结束 | 运行通知和服务结束；仍能使用固定提醒与专注 | 待测 |
| 导出并清空记录 | JSON 包含设置/规则/记录；清空后规则保留、旧事件不重新导入 | 待测 |
| 0.1.0 正式版覆盖安装 0.1.1 同签名正式版 | 小目标、娱乐组、规则、历史和专注保留，版本更新 | 待测 |
| 从 APP 检查更新/下载/安装 | 正式 Release 被识别，下载成功后校验，系统要求用户确认安装 | 待测 |

每日预算测试请临时设为 5 分钟；普通冷却与额度可能导致本应达到阈值的提醒被抑制，应先查看规则与日志。不要仅靠没有通知就认定监测出错。

## 可选 USB 调试

电脑端 SDK 的 platform-tools 已就绪；手机开启开发者选项和 USB 调试后连接，允许此电脑。确认 `adb devices` 中设备状态为 `device`，再安装 `adb install -r artifacts/shouxin-0.1.1-release.apk`。`-r` 是覆盖安装，不会主动清除本地数据。

CI 设备测试使用独立 debug 包，不覆盖正式版。要测正式版升级，请使用前后两个同签名 release APK，不能用 debug 包替代。
